# Nercio Malasse — Coding Portfolio

A responsive one-page developer portfolio built with plain HTML, CSS and JavaScript. No framework or build step is required.

## Run locally

1. Extract this folder.
2. Open `index.html` in a modern browser.
3. For local development, you may also use VS Code's Live Server extension.

## Personalise before publishing

- Confirm the display name, phone number and email address in `index.html` and `script.js`.
- Update the project summaries and status labels to match what is actually built and publicly shareable.
- Edit the skill-bar widths in `index.html`; they are visual placeholders rather than objective skill ratings.
- Add your real GitHub and LinkedIn profile links when available.
- Add a CV download only after placing your own CV in the site folder and linking it.
- The contact form uses a `mailto:` link. It opens the visitor's email application; it does not send mail by itself. For a hosted form that sends directly, connect a form service or backend and add spam protection.
- Google Fonts are loaded online. The site still works if the fonts cannot load, using fallback fonts.

## Publish

This is a static site and can be hosted on GitHub Pages, Netlify, Vercel or most ordinary web hosting services. Upload `index.html`, `styles.css` and `script.js` together, preserving the filenames.
